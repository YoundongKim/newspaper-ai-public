# 삼성전자·SK하이닉스 주가 요인 시계열

매일 한국시간 03:00에 국내·미국 증시를 조사하여 두 종목의 주가 움직임을 설명하는 근거를 누적합니다. 기업 일반론이나 기사 빈도만으로 그날의 원인을 확정하지 않습니다. 신규 유료 데이터 서비스는 사용하지 않습니다.

## 먼저 읽을 파일

- `latest.json` / `latest.md`: 최신 조사와 출처, 두 종목별 상위 요인 및 반대 근거, 쇼츠 소재.
- `history.json`: `(한국 거래일, 종목코드)`가 중복되지 않는 시계열. 주말·휴장일 재조사를 추가 거래일로 세지 않습니다.
- `rolling.json`: 최근 5/20/60 국내 거래일의 요인 변화와 관측 횟수. 표본이 부족하면 명시합니다.
- `factor_registry.json`: 고정 요인 ID와 정의. ID를 날짜마다 바꾸지 않습니다.
- `daily/YYYY-MM-DD.json` / `.md`: KST 조사 날짜별 원본 기록. 사후 정정은 이유를 남깁니다.
- `index.json`: 누적 날짜·파일 목록. `RUNBOOK.md`: 조사·검증·발행 절차.

## 시간의 기준

03시 보고서는 직전 완료된 **KRX 정규장**을 설명합니다. 예를 들어 11월 11일 03시 조사에는 11월 10일 국내장이 들어갑니다. 미국 시장은 이전 완료 세션과 현재 진행 세션을 분리합니다. 국내장 마감 후 시작한 미국장의 소식은 이미 끝난 국내장의 원인으로 쓰지 않고 다음 국내장 신호로 기록합니다. 미국장은 통상 한국시간 서머타임 05시, 그 외 06시에 정규장을 마치므로 03시 수치는 종가가 아닙니다. 거래소 휴장·조기 폐장·거래시간 변경은 매 실행 확인합니다.

bootstrap 기록은 실제 작성 시각의 사후 조사입니다. 03시에 알 수 있었던 자료인 것처럼 소급하지 않습니다. 뉴스 발표 시각, 사건 시각, 실제 관측 시각, 수집 시각을 구분합니다. 사후 마감기사가 전하는 당일 사건을 설명에는 쓸 수 있지만 당시 선행 정보로 알고 있었다고 처리하지 않습니다.

## 매일 확인할 요인

미국 반도체 / 글로벌 위험선호 / 금리·거시 / 원달러 / 외국인 / 기관·ETF / 메모리 가격·재고 / HBM 인증·양산 / AI 고객 투자 / 실적 기대 / 공급·설비투자 / 정책·수출규제 / 기업 사건·주주환원 / 포지셔닝 / 삼성 비메모리.

이 목록은 조사 후보군이며 중요도 순위가 아닙니다. 종목별로 당일 설명력이 높은 후보 0~3개와 확신도·근거·반대 근거·신규성·정보 시점을 남깁니다. 당일 새 HBM 뉴스가 없는데도 상승의 원인을 HBM으로 고정하지 않습니다. 주가를 움직인 요인이 불명확하면 불명확하다고 씁니다.

## 사실과 해석

- 사실: 거래소 종가·등락률·수급, 공시·실적, 발표와 공개 시점 등 검증한 수치.
- 해석: SOX 반등이 국내 반도체의 위험선호 회복에 연결됐다는 설명 등. 사건 시점·동종주·시장 대비 차이·기사의 해석을 함께 확인합니다.
- 반례: 외국인이 팔았는데 주가가 오른 날, 호재에도 하락한 날, 두 종목이 반대로 움직인 날. 이런 관측을 버리지 않습니다.
- 수급은 매매의 결과이기도 하므로 외국인 순매수만으로 원인이나 상승 예측력을 주장하지 않습니다. 지수 전체 수급과 개별 종목 수급을 구분합니다.
- 요인 순위는 **근거에 따른 편집 판단**입니다. “HBM이 상승의 70%를 설명” 같은 숫자를 계산 없이 만들지 않습니다.

## 수치·데이터 품질

가격의 기본은 KRX 정규장 전일 종가→당일 종가입니다. 확보되면 시초가 갭과 장중 등락을 따로 계산하고, 두 수익률을 단순히 더하지 않습니다. NXT·ADR·선물·ETF는 별도 시장과 기준시각으로 표시합니다. 기사에 삽입된 실시간 가격 위젯을 기사 작성 당시 종가로 쓰지 않습니다.

우선 거래소·공시·기업 IR·공식 통계·거래소 지수 자료를 확인합니다. 접근이 안 되면 서로 독립적인 신뢰 가능한 보도의 수치와 집계 범위를 대조합니다. 원출처가 같은 전재 기사 두 건은 독립 검증 두 건이 아닙니다. 불일치·잠정치·결측은 이유와 함께 남기고 값을 추정해 채우지 않습니다. HBM 인증·수주 등의 익명 보도는 회사의 확정 발표와 구분합니다. 기사 원문·유료 원자료를 복제하지 않고 필요한 사실과 자체 요약, 원문 링크만 공개합니다.

## 시계열로 무엇을 볼 수 있나

5일: 이번 주 지배적 설명 후보와 삼성/하이닉스의 차이. 20일: 요인 교체와 호재/악재에 대한 비대칭 반응. 60일: 관계의 지속·약화·반전과 시장 국면 차이.

요인 언급 횟수·상위 선정 횟수는 실제 주가 기여도와 다릅니다. `rolling.json`의 상관계수도 적어도 선행 수치 20쌍과 5개 이상의 서로 다른 값이 있을 때만 표시하는 탐색 지표입니다. 미래 검증·통제변수 보정·통계적 유의성 검정을 하지 않았으므로 인과 또는 예측력으로 설명하지 않습니다. 정식 모델이 필요하면 별도 승인된 연구로 시장/업종 중복·다중공선성·시점 누수·기간 외 성능을 검증합니다.

## 쇼츠에 활용

매일 근거가 충분한 소재만 0~2개 남깁니다. 훅, 의외인 이유, 확인 사실, 반대 해석, 다음 확인 변수와 출처가 포함됩니다. 주제 수를 채우기 위해 소재를 만들지 않으며, 이번 작업은 영상 제작이나 소셜 게시 예약을 포함하지 않습니다. “같은 반도체인데 왜 수급이 갈렸나”, “외국인이 팔았는데 왜 올랐나”처럼 설명할 가치가 있는 관측을 우선합니다.
